## Problem and behavior

The former topic-only workflow exported RSS leads without checking whether article bodies were relevant. Real Pokémon runs retrieved baseball, grocery and Chicago pages and yielded no usable evidence. This change adds bounded bilingual research, original-source discovery, exact-span citations, explicit research/script milestones and gated documentary production.

Research combines DDGS with Bing, validates suggested encyclopedia pages through Wikipedia-API, follows actual external references, and prioritizes original-document leads. BM25 retrieves relevant passages across retained bodies; pySBD preserves source offsets. Models select quote IDs and cite closed source/quote pairs; the program copies exact source spans, rejects unknown IDs, and audits corroboration, dates, independence and meaning. One follow-up round targets actual missing claims and uncertainties, with cached selections and bounded format correction.

Users receive PROGRESS.md and source/evidence diagnostics. RESEARCH.md contains only retained claims after the evidence audit. Unsupported candidates are excluded individually, while every retained claim must still pass the original citation, corroboration, date and semantic checks and the four-claim minimum. SCRIPT.md is written only after all script checks, including answering the requested topic, pass. Separate Commons metadata inspection produces FOOTAGE_GAPS.md without downloading or pretending to recognize gameplay. RESEARCH_READY and SCRIPT_READY never mean a finished film. The movie path retains strict licensing, PySceneDetect, actual-frame vision matching, measured Chinese narration/captions, 1080p FFmpeg, thumbnail and attribution outputs; unsupported claims, missing gameplay and failed quality checks stop production.

Narration is measured as decoded PCM and encoded to AAC once for the whole edit, fixing cumulative decoder padding from per-scene AAC concatenation. QA compares stream and decoded audio lengths. Durable stage checkpoints, cancellation handling and Actions annotations preserve useful failure evidence. Existing render.py, Kokoro, Piper, Pixabay and Wikimedia workflows remain available.

## Provider configuration

Real Actions runs exposed an invalid default: GitHub officially retired GitHub Models, including inference, on 2026-07-30. That provider is now rejected explicitly. The user's latest Gemini choice is recorded in config/model.json (official OpenAI-compatible endpoint / gemini-flash-latest). Optional `LLM_BASE_URL` / `LLM_MODEL` overrides work from Variables or Secrets. A separate small service-check workflow rejects leftover GPT overrides before sending a Gemini key, validates actual text+vision inference with a synthetic image, and checks search, Commons and Taiwan TTS independently. Keys are never read from configuration files; GitHub tokens are not reused as model keys. Eligible free-tier access is not a promise of sufficient daily capacity.

## Usage and acceptance remaining

Actions → One Topic Game Documentary → choose the feature branch → Chinese topic and goal (research, script, movie). One Topic Research and Script provides a lighter research workflow plus an independent footage-readiness report. New workflow dispatch becomes available once its file exists on the default branch; branch topic-list pushes already work. Batch supports 1–3 topics; the production schedule is 09:20 Asia/Taipei after merge. Test queues are cleared after validation. Failed gates retain reports and upload no finished MP4.

Gemini credentials and text/vision access are verified; no replacement key is requested. Free-tier capacity depends on the account and provider. Real rights-cleared Pokémon footage, visual matching, narration naturalness and a complete 10–15 minute film remain unverified. Script duration estimates require actual voice measurement; Commons metadata candidates are not visual or legal guarantees, and current policy does not support every valid license. Cloud draft changes do not populate repository secrets or apply network policy. The cloud GitHub API remains blocked, so no PR has been created automatically.
